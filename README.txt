Low Poly Drift (PWA)

Upload this whole folder to any HTTPS web host (GitHub Pages, Netlify, your own server).
Open index.html's URL on your phone, then use "Add to Home Screen" / "Install app".
It works offline after the first load. three.js is bundled, so no CDN is needed.

When you update the game, change CACHE in sw.js (for example to low-poly-drift-v2) so installed copies refresh.
